## Defect and Behavior Register
1. **Tab/Popup Blindness (`T08`):** Clicking a `target="_blank"` link opens a new foreground Chrome tab (`New Window - Google Chrome for Testing` in OS `list_desktop_windows`), while `list_sessions()` and `discover()` remain pinned to the original background tab with no tab listing or switching tool.
2. **Win32 `#32770` Save As `ValuePattern` Desync & Silent Modal (`T15`):** `act(e78, "type", path)` uses `ValuePattern.SetValue` on pre-populated `Edit` (`automation_id="1001"`) and reports `verified:true` (`len=109`), yet `IFileSaveDialog` still submits the illegal pre-filled document title (`CUL-LIVE-2026 | Cairo القاهرة.txt اسم الملف غير صحيح`), and `discover()` omits the alert dialog text. File Open (starting empty `""`) did succeed via `ValuePattern`.
3. **SSRF Boundary Gap (`T17`):** `navigate()` blocked `file://` (`PermissionDenied`), but passed `http://127.0.0.1:9222/json` and `http://169.254.169.254/latest/meta-data/` through to `Page.goto(...)` (leaving `ERR_CONNECTION_REFUSED` and `ERR_ADDRESS_UNREACHABLE`, and leaving `s20` displaying `169.254.169.254` while `list_sessions()` still showed `/dynamic-controls`).
4. **Cross-Origin OOPIF & Chromium `RootWebArea` Blindness (`T01`, `T04`, `T16`):** Cross-origin iframes (`#google_vignette` in `T01`, YouTube player in `T04`) exposed zero inner controls and `BLIND_REGIONS:0`; Desktop UIA attached to Chrome (`s21` in `T16`) collapsed the `1280x720` page into one `textbox` (`RootWebArea`) with `BLIND_REGIONS:0`.
5. **Misclassified / Value-Opaque HTML Input Types (`T01`, `T02`, `T04`, `T05`, `T06`, `T10`, `T11`):**
   - `<input type="date">` (`T01`), `<input type="range">` (`T06`), `<input type="search">` (`T10`, `T11`), and same-origin iframe controls (`T04`) fell back to `role="clickable"` (`source=isClickable`); calling `type` on `<input type="date">` returned `ok:true` while corrupting `2026-12-01` into `02/02/61201`.
